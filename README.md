AzCode es un lenguaje educativo para practicar programación mediante instrucciones sencillas. Sus palabras
reservadas están en portugués y sus programas se guardan en archivos de texto con extensión .az. Permite
trabajar con variables, operaciones, entrada de datos, funciones simples, repeticiones y selección de
opciones.
Esta guía explica lo necesario para escribir y ejecutar programas, y preparar otra PC con Windows desde cero.
La ejecución se realiza en PowerShell con Python; no requiere la extensión de AzCode ni un botón especial
del editor.
